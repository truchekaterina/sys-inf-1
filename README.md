# Стенд «Вывод → Реестр»

Два локальных адреса. Сотрудник, специалист, аудитор и администратор ходят на первый. Карточки пишет только фильтр, на второй адрес, со служебным ключом.

| Адрес | Кто | Страница |
| --- | --- | --- |
| `127.0.0.1:8091` | люди, префикс `/api/v1` | http://127.0.0.1:8091/docs |
| `127.0.0.2:8092` | реестр, префикс `/db/v1` | http://127.0.0.2:8092/docs |

Пароль демо-входов: `lab`. Ключ реестра: `lab-service`.

## Запуск

```powershell
cd prototype
python serve.py
```

Окно не закрывать. Остановка: Ctrl+C.

При каждом запуске базы создаются заново, а `config/settings.txt` копируется из `config/settings.example.txt`. Там три фразы: «пароль», «ключ доступа», «закрытый узел». N = 3. T, T1 и T2 на стенде — секунды; 0 значит повтор сразу после ответа реестра.

На странице людей в **Authorize** вставляется токен без слова Bearer: `lab.employee`, `lab.specialist`, `lab.auditor`, `lab.admin`.  
На странице реестра в **Authorize** вставляется `lab-service`.

Прогон тех же шагов без браузера:

```powershell
python tests/check_scenarios.py
```

## Какой файл за что отвечает

| Файл или папка | Зачем |
| --- | --- |
| `serve.py` | Держит оба адреса, пока окно открыто |
| `src/ui_server.py` | Маршруты людей и проверка токена |
| `src/rights.py` | Какая роль какой путь может вызвать |
| `src/ui_chat.py` | Вопрос, поиск фразы, уровень L3 или L4 |
| `src/phrases.py` | Поиск фразы и кусок документа |
| `src/ui_journal.py` | Журнал: реестр и очередь недоставленных |
| `src/ui_rules.py` | Экран «Правила» |
| `src/ui_calls.py` | Журнал вызовов webhook |
| `src/webhook.py` | Отправка карточки, повтор, пометка |
| `src/db_server.py` | Маршруты реестра и служебный ключ |
| `src/db_cards.py` | Приём карточки и запрет кода `pass` |
| `src/db_stand.py` | Переключатель «реестр молчит» |
| `src/settings_file.py` | Файл `config/settings.txt` |
| `src/store_filter.py` | База фильтра `data/filter.db` |
| `src/store_registry.py` | База реестра `data/registry.db` |
| `sql/filter.sql` | Таблицы чата, очереди и вызовов |
| `sql/registry.sql` | Таблицы карточек и доставок |
| `openapi/` | Контракты для Swagger |
| `swagger/` | Страница Swagger без интернета |
| `tests/check_scenarios.py` | Прогон сценариев |

Список фраз в реестр не копируется. Ответ сотруднику не содержит фразу, уровень и кусок документа.
